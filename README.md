# Greenfield Academy

Monorepo for the Greenfield Academy website.

| Folder      | What                                                      |
| ----------- | --------------------------------------------------------- |
| `frontend/` | Next.js website (App Router, TypeScript). See its README. |
| `backend/`  | REST API (Node.js or Python), not started yet.            |

The frontend runs against a mock API until the backend exists; the contract is in
`frontend/docs/api-contract.md`.
